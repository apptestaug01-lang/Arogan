Gap 1.1 — No S3/B2 Storage Integration HIGH

Files are likely stored locally or in DB blobs. No S3 or Backblaze B2 SDK is configured. Documents never reach the 10GB bucket.

✅ Fix: Integrate @aws-sdk/client-s3 for S3 or backblaze-b2 for B2. Stream file directly to bucket on upload — never write to local disk.

Gap 1.2 — No Bucket Capacity Management HIGH

The 10GB bucket limit is not tracked anywhere. A single large batch upload can silently overflow the bucket causing all subsequent uploads to fail.

✅ Fix: Track cumulative file sizes in DB. Before each upload, check: usedBytes + fileSize <= 10GB. Alert at 80% (8GB). Reject at 95% (9.5GB).

Gap 1.3 — No Secure Pre-signed URLs HIGH

Documents (PAN, Aadhaar, Bank Statements) are highly sensitive. Without pre-signed URLs, files may be publicly accessible or require permanent credentials to access.

✅ Fix: Generate pre-signed URLs with 15-minute expiry for every file access. Never expose permanent bucket URLs.

Gap 1.4 — No Organized Folder Structure MEDIUM

Files dumped flat into bucket root — impossible to manage at scale. No way to find documents by user, type, or date.

✅ Fix: Use path: /{userId}/{documentType}/{year}/{month}/{fileHash}.pdf
Example: /user123/pan/2026/09/abc123.pdf

Gap 3.1 — No Field Completeness Check HIGH

After extraction, there is no check to verify all expected fields are present. Missing fields are silently dropped — the JSON looks complete but has holes.

✅ Fix: Define required fields per document type. After extraction, compare against schema. Output missingFields: ["fatherName", "dateOfBirth"] in JSON — never drop silently.

Gap 3.2 — No Raw Text Preservation HIGH

If a field extraction fails, the raw OCR text is discarded. The original data is permanently lost with no way to recover or re-process.

✅ Fix: Always store rawText (full OCR output) alongside structured JSON in S3/B2. This ensures data is never truly lost even if parsing fails.

Gap 3.3 — No Per-field Confidence Score MEDIUM

A single document-level confidence score doesn't reveal which specific fields were extracted poorly. Bad field values are indistinguishable from good ones.

✅ Fix: Add per-field confidence: { "name": { "value": "John", "confidence": 0.98 } }. Flag fields below 0.7 for manual review.

Gap 3.4 — Multi-page Document Data Loss HIGH

Bank statements with 50+ pages may only process the first page. All transactions from subsequent pages are silently lost.

✅ Fix: Process all pages in sequence. Merge transactions[] arrays across pages. Store totalPages and processedPages in JSON to verify completeness.

Gap 4.1 — No Versioned JSON Output MEDIUM

When a document is re-processed (e.g., better model available), the old JSON is overwritten. Historical extraction data is permanently lost.

✅ Fix: Store JSON with version suffix in S3/B2: /user123/pan/abc123_v1.json, abc123_v2.json. Keep latest pointer in DB.

Gap 4.2 — JSON Not Stored Back to S3/B2 MEDIUM

Extracted JSON is only saved to the database. It is not written back to the S3/B2 bucket alongside the original document, making the bucket incomplete.

✅ Fix: After extraction, write {fileHash}.json to same S3/B2 path as original PDF. Bucket should contain both: abc123.pdf and abc123.json.

Gap 4.3 — No Checksum Validation MEDIUM

No way to verify JSON integrity after storage. A corrupted or truncated JSON file in S3/B2 would be read and used without detection.

✅ Fix: Compute SHA-256 of JSON string before upload. Store checksum in DB. Verify checksum on every read from S3/B2.

Gap 4.4 — No Structured Error JSON LOW

When extraction fails, no JSON is produced at all. Downstream systems get null/undefined instead of a structured error they can handle.

✅ Fix: Always return a JSON even on failure: { "status": "FAILED", "reason": "OCR timeout", "rawText": "...", "missingFields": ["all"] }

Gap 5.1 — No Queue for Large Uploads MEDIUM

With a 10GB bucket, large batches of documents are processed synchronously. A single large PDF can block the entire pipeline and timeout the HTTP request.

✅ Fix: Upload to S3/B2 first (fast), then push extraction job to a queue (BullMQ/Redis). Return job ID immediately. Client polls for status.

Gap 5.2 — No Storage Cost Tracking LOW

Backblaze B2 charges per GB stored and per GB downloaded. Without tracking, costs can spike unexpectedly especially with large bank statements.

✅ Fix: Track file sizes in DB. Calculate monthly storage usage. Show dashboard with GB used, estimated cost, and per-document-type breakdown.

Gap 5.3 — No Lifecycle Policy LOW

Old documents, failed uploads, and temp files accumulate in the bucket forever. The 10GB limit will be hit faster than expected.

✅ Fix: Set lifecycle rules — archive originals after 90 days, delete failed/temp uploads after 30 days, compress JSONs older than 1 year.

// backend/src/services/storageService.ts
import { S3Client, PutObjectCommand, GetObjectCommand } from '@aws-sdk/client-s3';
import { getSignedUrl } from '@aws-sdk/s3-request-presigner';

const s3 = new S3Client({
  region: process.env.S3_REGION,
  credentials: {
    accessKeyId: process.env.S3_ACCESS_KEY!,
    secretAccessKey: process.env.S3_SECRET_KEY!,
  },
  // For Backblaze B2, add endpoint:
  endpoint: process.env.B2_ENDPOINT, // e.g. https://s3.us-west-004.backblazeb2.com
});

const BUCKET = process.env.S3_BUCKET!;
const MAX_BYTES = 10 * 1024 * 1024 * 1024; // 10GB
const ALERT_THRESHOLD = 0.8; // 80%

export async function uploadDocument(
  userId: string, docType: string,
  fileHash: string, fileBuffer: Buffer,
  mimeType: string
): Promise<string> {
  // 1. Check capacity
  const usedBytes = await getUsedStorageBytes(); // from DB
  if (usedBytes + fileBuffer.length > MAX_BYTES * 0.95) {
    throw new Error('Storage limit reached. Cannot upload.');
  }
  if (usedBytes + fileBuffer.length > MAX_BYTES * ALERT_THRESHOLD) {
    await sendStorageAlert(usedBytes); // notify admin
  }

  // 2. Structured path
  const now = new Date();
  const key = `${userId}/${docType}/${now.getFullYear()}/${String(now.getMonth()+1).padStart(2,'0')}/${fileHash}.pdf`;

  // 3. Upload
  await s3.send(new PutObjectCommand({
    Bucket: BUCKET, Key: key,
    Body: fileBuffer, ContentType: mimeType,
    ServerSideEncryption: 'AES256',
  }));

  // 4. Track in DB
  await updateStorageUsage(fileBuffer.length);
  return key;
}

export async function getPresignedUrl(key: string): Promise<string> {
  const cmd = new GetObjectCommand({ Bucket: BUCKET, Key: key });
  return getSignedUrl(s3, cmd, { expiresIn: 900 }); // 15 min
}

// backend/src/modules/documentExtraction/fieldValidator.ts
const REQUIRED_FIELDS: Record<string, string[]> = {
  PAN: ['panNumber', 'name', 'fatherName', 'dateOfBirth'],
  AADHAAR: ['aadhaarNumber', 'name', 'dateOfBirth', 'gender', 'address'],
  GST: ['gstin', 'legalName', 'registrationDate', 'businessType', 'state'],
  ITR: ['assessmentYear', 'pan', 'grossTotalIncome', 'taxPaid', 'filingDate'],
  BANK_STATEMENT: ['accountNumber', 'accountHolder', 'ifscCode', 'openingBalance', 'closingBalance', 'transactions'],
};

export function validateExtraction(docType: string, extracted: Record<string, any>) {
  const required = REQUIRED_FIELDS[docType] || [];
  const missingFields = required.filter(f => extracted[f] === null || extracted[f] === undefined);
  return {
    ...extracted,
    missingFields,
    extractionStatus: missingFields.length === 0 ? 'COMPLETE' : 'PARTIAL',
  };
}

// Per-field confidence wrapper
export function wrapWithConfidence(fields: Record<string, any>, scores: Record<string, number>) {
  return Object.fromEntries(
    Object.entries(fields).map(([k, v]) => [k, { value: v, confidence: scores[k] ?? 0 }])
  );
}

// backend/src/services/jsonStorageService.ts
import crypto from 'crypto';

export async function storeExtractionJson(
  s3Key: string, jsonData: object, version: number
): Promise<string> {
  const jsonStr = JSON.stringify(jsonData, null, 2);
  const checksum = crypto.createHash('sha256').update(jsonStr).digest('hex');

  // Store versioned JSON next to original
  const jsonKey = s3Key.replace('.pdf', `_v${version}.json`);

  await s3.send(new PutObjectCommand({
    Bucket: BUCKET, Key: jsonKey,
    Body: jsonStr, ContentType: 'application/json',
    Metadata: { checksum, version: String(version) },
  }));

  // Save checksum to DB for integrity verification
  await saveChecksumToDB(jsonKey, checksum, version);
  return jsonKey;
}

// Always return structured JSON even on failure
export function buildErrorJson(docType: string, reason: string, rawText: string) {
  return {
    documentType: docType,
    status: 'FAILED',
    reason,
    rawText,
    missingFields: ['all'],
    extractedAt: new Date().toISOString(),
  };
}
