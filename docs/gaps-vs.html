1. No File Type Validation HIGH

Frontend fileProcessor.ts lacks strict MIME type and extension checks before upload. Invalid files can enter the pipeline and cause unexpected errors.

Fix: Add allowlist validation — accept only PDF, DOCX, XLSX, PNG, JPG. Reject all others with a clear error message before upload starts.

2. No File Size Limit HIGH

Large files (e.g., 100MB PDFs) can crash the extraction pipeline, cause memory issues, or timeout the server.

Fix: Enforce a max file size of 20MB on both frontend (before upload) and backend (in middleware). Return HTTP 413 for oversized files.

3. No Upload Progress Feedback MEDIUM

Users receive no real-time feedback during file upload. For large files this creates a poor UX — users don't know if the upload is working.

Fix: Implement a progress bar using XHR onprogress events or fetch with ReadableStream. Show percentage and estimated time.

4. No Duplicate File Detection MEDIUM

The same document can be uploaded multiple times, causing redundant processing, wasted storage, and duplicate JSON records.

Fix: Hash file content using SHA-256 on the frontend before upload. Check the hash against existing records in the DB. Warn user if duplicate found.

5. Incomplete Converter Coverage HIGH

unknown.ts fallback converter silently fails for unsupported formats with no user notification. Users don't know their file wasn't processed.

Fix: Return a clear error response listing supported formats when an unknown type is detected. Log the unsupported MIME type for monitoring.

6. No JSON Schema Validation HIGH

Extracted JSON is not validated against a defined schema before saving to the database. Malformed or incomplete data can corrupt downstream processes.

Fix: Define JSON schemas per document type (Aadhaar, PAN, GST, etc.) using Zod or Ajv. Validate every extraction output before persisting.

7. No Fallback for Partial LLM Extraction HIGH

llmExtractor.ts has no fallback if LLM partially fails. Partial data may be saved as complete, leading to silent data quality issues.

Fix: Add confidence scoring per field. Flag extractions below threshold as PARTIAL. Implement retry with a different prompt or fallback to regex extractor.

8. Inconsistent JSON Structure Across Extractors MEDIUM

Extractors (Aadhaar, PAN, GST, ITR, Bank Statement) may return different JSON shapes, making downstream consumption unreliable.

Fix: Define a common base schema with document-specific extensions. All extractors must conform to the base schema.

9. No Extraction Status Tracking MEDIUM

No way to know if a document is pending, processing, or failed after upload. Users and admins are blind to pipeline state.

Fix: Add a status field (PENDING / PROCESSING / COMPLETED / FAILED) in the DB. Expose a GET /documents/:id/status API endpoint.

10. No Retry Mechanism MEDIUM

Failed conversions are not retried automatically, requiring manual intervention. Transient errors (network, LLM timeout) cause permanent failures.

Fix: Implement exponential backoff retry (max 3 attempts) in worker.ts and scheduler.ts. Dead-letter queue for permanently failed jobs.

11. No Audit Log LOW

No record of who uploaded what document and when, making compliance and debugging difficult.

Fix: Log upload events with user ID, timestamp, file hash, file name, and extraction result status. Store in a separate audit table.

// frontend/src/lib/upload/fileProcessor.ts

const ALLOWED_TYPES = ['application/pdf','application/vnd.openxmlformats-officedocument.wordprocessingml.document',
  'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet','image/png','image/jpeg'];
const MAX_SIZE_MB = 20;
const MAX_SIZE_BYTES = MAX_SIZE_MB * 1024 * 1024;

export function validateFile(file: File): { valid: boolean; error?: string } {
  if (!ALLOWED_TYPES.includes(file.type)) {
    return { valid: false, error: `Unsupported file type: ${file.type}. Allowed: PDF, DOCX, XLSX, PNG, JPG` };
  }
  if (file.size > MAX_SIZE_BYTES) {
    return { valid: false, error: `File too large: ${(file.size/1024/1024).toFixed(1)}MB. Max allowed: ${MAX_SIZE_MB}MB` };
  }
  return { valid: true };
}

// backend/src/middleware/uploadLimits.ts
import multer from 'multer';
export const uploadMiddleware = multer({
  limits: { fileSize: 20 * 1024 * 1024 },
  fileFilter: (_req, file, cb) => {
    const allowed = ['application/pdf','image/png','image/jpeg',
      'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
      'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'];
    cb(null, allowed.includes(file.mimetype));
  }
});

// Duplicate detection — hash file before upload
async function hashFile(file: File): Promise<string> {
  const buffer = await file.arrayBuffer();
  const hashBuffer = await crypto.subtle.digest('SHA-256', buffer);
  return Array.from(new Uint8Array(hashBuffer)).map(b => b.toString(16).padStart(2,'0')).join('');
}

// Upload with progress
function uploadWithProgress(file: File, url: string, onProgress: (pct: number) => void) {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    xhr.upload.onprogress = (e) => { if (e.lengthComputable) onProgress(Math.round(e.loaded/e.total*100)); };
    xhr.onload = () => resolve(xhr.response);
    xhr.onerror = reject;
    xhr.open('POST', url);
    const form = new FormData();
    form.append('file', file);
    xhr.send(form);
  });
}

// backend/src/modules/documentArchive/converters/unknown.ts

    'application/vnd.openxmlformats-officedocument.wordprocessingml.document',
    'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet'];
  throw new Error(`Unsupported file type: "${mimeType}". Supported: ${supported.join(', ')}`);
}

// In llmExtractor.ts — add confidence + fallback
async function extractWithFallback(text: string, docType: string) {
  try {
    const result = await llmExtract(text, docType);
    const confidence = calculateConfidence(result);
    if (confidence < 0.7) {
      return { ...result, status: 'PARTIAL', confidence };
    }
    return { ...result, status: 'COMPLETE', confidence };
  } catch {
    return { status: 'FAILED', confidence: 0, fields: {} };
  }
}

// backend/src/modules/documentArchive/worker.ts
async function processWithRetry(docId: string, maxRetries = 3) {
  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      await updateStatus(docId, 'PROCESSING');
      const result = await extractDocument(docId);
      await updateStatus(docId, 'COMPLETED');
      await writeAuditLog(docId, 'EXTRACT', 'SUCCESS');
      return result;
    } catch (err) {
      const delay = Math.pow(2, attempt) * 1000; // 2s, 4s, 8s
      if (attempt === maxRetries) {
        await updateStatus(docId, 'FAILED');
        await writeAuditLog(docId, 'FAIL', String(err));
        throw err;
      }
      await sleep(delay);
    }
  }
}
